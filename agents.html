AGENTS

An agent does one job, every time it is asked.

We build AI agents, run them, and charge for the work they do. This page explains what that means in practice, and how we use the same approach to run Arithim.

WHAT AN AGENT IS

An agent is software with one job. It has the access it needs for that job, an AI model to work through each case, and clear rules about when to stop and ask a person. It starts on a schedule, or when something arrives, such as an invoice or an email.

Take accounts payable. An agent could read supplier invoices as they arrive, check each one against the purchase order, queue the ones that match for approval, and send anything that does not match to the right person with a note on why.

WHERE IT RUNS
In your environment
The agent runs inside your own cloud account or servers, next to your data. Useful when data cannot leave your estate.
On Arithim hosting
We host and run the agent for you. You give it access to the systems it needs, and we look after the rest.

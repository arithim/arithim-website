FREQUENTLY ASKED

Questions about Data API and MCP

What is the Data API and MCP?

A read-only API and an MCP server that give your tools and AI assistants the same grid, project and holdings data we use, with sources.

How much does it cost?

From £18,000 a year, excluding VAT, depending on use.

What is MCP?

Model Context Protocol, a standard way for AI assistants to call tools and read data. Our MCP server lets your assistant ask questions of the data.

Can I resell the data?

No. Each record carries its licence, and your use must respect it.

Is it part of Site Finder?

It is a separate product. The Site Finder platform includes access for its own team, and the API is available on its own.

Don't Ship Slop

Tarun Bulchandani · Arithim

The hook

I reviewed the design.

I did not review the code.

The product

Find Me A Job.

A product I built myself. An AI assistant wrote part of the code.

What it did

It copied whole job adverts into every user's row.

The problem with slop

Nothing broke.

  • The page loaded
  • The tests passed

The fix

I read the code. Then I fixed it.

Two reviews

A design review is not a code review.

Design review

I did it. It looked fine.

Code review

I skipped it. The cost landed here.

Where the cost lands

AI makes writing code cheap.

Reviewing it is still work, and that is where the cost shows up.

The review standard

Before you merge AI-written code.

  • Read the diff, not just the summary
  • Check what it stores, not only what it shows
  • Ask what happens when this is multiplied by every user

Over to you

What is your review rule for AI-written code?

On Monday

Adopt the standard.

  • Put the three questions in your pull request template
  • Make someone read the diff before merge
  • Look at what the code stores
